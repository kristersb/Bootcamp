# [Test Suites] Resetting the filter to "All statuses" shows every suite

**Severity:** Minor
**Status:** draft

## Preconditions
Suites exist with at least two different statuses. Open /test-suites and note the total number of rows.

## Steps
1. In the status filter, select "draft".
2. In the status filter, select "All statuses".

## Expected Result
After step 2 the list shows the same total number of suites as before the filter was applied.
