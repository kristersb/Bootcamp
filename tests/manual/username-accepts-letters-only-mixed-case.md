# [Username] Accepts a username with letters only in mixed case

**Severity:** Minor
**Status:** draft

## Preconditions
- User is on the sign-up page.
- The username "JohnDoe" is not already taken.

## Steps
1. Enter "JohnDoe" in the username field
2. Complete the other required fields
3. Submit the form

## Expected Result
The username is accepted and the account is created with the username "JohnDoe", with the original capitalization kept.
