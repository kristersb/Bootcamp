# [Username] Rejects a username that is already taken

**Severity:** Critical
**Status:** draft

## Preconditions
- User is on the sign-up page.
- An account with the username "tester01" already exists.

## Steps
1. Enter "tester01" in the username field
2. Complete the other required fields
3. Submit the form

## Expected Result
The form is not submitted and an error message under the username field states the username is already taken. No second account is created.
