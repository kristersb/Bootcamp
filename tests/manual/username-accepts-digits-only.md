# [Username] Accepts a username with digits only

**Severity:** Minor
**Status:** draft

## Preconditions
- User is on the sign-up page.
- The username "12345" is not already taken.

## Steps
1. Enter "12345" in the username field
2. Complete the other required fields
3. Submit the form

## Expected Result
The username is accepted and the account is created with the username "12345".
