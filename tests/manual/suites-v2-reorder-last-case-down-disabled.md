# [Test Suites] The down arrow is disabled on the last case

**Severity:** Minor
**Status:** draft

## Preconditions
A suite contains "Case A" (1), "Case B" (2). Open its detail page.

## Steps
1. Look at the "↓" button on the "Case B" row.
2. Click it.

## Expected Result
The "↓" button on the last row is disabled. Clicking it does nothing and the order stays Case A, Case B. The "↑" button on that row is enabled.
