# [Test Suites] Move a case up with the arrow button

**Severity:** Critical
**Status:** draft

## Preconditions
A suite contains "Case A" (1), "Case B" (2), "Case C" (3). Open its detail page.

## Steps
1. Click the "↑" button on the "Case C" row.

## Expected Result
The list reads 1. Case A, 2. Case C, 3. Case B. The position numbers update.
