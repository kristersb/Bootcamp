# [Test Suites] Move a case down with the arrow button

**Severity:** Critical
**Status:** draft

## Preconditions
A suite contains "Case A" (1), "Case B" (2), "Case C" (3). Open its detail page.

## Steps
1. Click the "↓" button on the "Case A" row.

## Expected Result
The list reads 1. Case B, 2. Case A, 3. Case C. The position numbers update. The hint returns to "Drag a row, or use the arrow buttons, to change the run order." once saving ends.
