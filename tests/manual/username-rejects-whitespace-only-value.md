# [Username] Rejects a username made only of whitespace

**Severity:** Major
**Status:** draft

## Preconditions
User is on the sign-up page.

## Steps
1. Enter 5 space characters in the username field
2. Complete the other required fields
3. Submit the form

## Expected Result
The form is not submitted and an error message under the username field states the username is required or contains invalid characters. No account is created.
